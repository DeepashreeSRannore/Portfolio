# Deepashree Srinivasa Rao Rannore - Portfolio Website

A responsive and interactive portfolio website showcasing my professional experience, projects, skills, and achievements.

## 🌐 Live Website

**Deployed on Vercel**: https://tinyurl.com/DeepaRannorePortfolio

## ✨ Features

- **Three Theme Modes**: 
  - 🌌 Dark Galaxy Theme (with twinkling stars and comet)
  - 🌿 Light Nature Theme (with falling leaves and flowers)
  - 🤖 Tech Theme (with AI/ML icons and circuit patterns)

- **Responsive Design**
- **Smooth Animations** 
- **Interactive Navigation**
- **Dynamic Backgrounds** 

## 🛠️ Technologies Used

- **React** - UI library
- **Vite** - Build tool
- **Framer Motion** - Animations
- **React Icons** - Icon library
- **CSS3** - Styling with custom properties
